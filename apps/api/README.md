# @mwp/api

Fastify-Service: Scoring der Vergleichs-Engine (/internal/evaluations),
Pflege-Admin (/admin/vergleich, Basic-Auth, ADR 0002), Newsletter-
Anmeldung (Brevo DOI), Affiliate-Redirects (/go) und Praxisfinder-API
(/api/praxen, PostGIS-Umkreissuche).
Spricht als einziger Dienst die Postgres-Schemata `vergleich` und
`praxen` an.
